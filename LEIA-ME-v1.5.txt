O que foi corrigido:
1. O motor diário agora usa a janela de germinação, blackout e colheita de cada variedade para definir a fase. Isso evita que variedades lentas, como coentro, sejam classificadas como "Colheita" no dia 7 apenas por causa de uma faixa genérica.
2. Girassol: pré-molho deixou de ser recomendado e a janela foi ajustada para 8–10 dias, seguindo o método atual consultado da On The Grow.
3. Coentro: janela conservadora de 14–28 dias, pré-molho opcional/recomendado no método atual consultado, e não é mais marcado como primeira escolha para iniciantes.
4. Manjericão e amaranto não são mais marcados como primeiras opções para iniciantes.
5. Foram adicionadas fontes internas de verificação ao catálogo. Elas não aparecem na interface do aplicativo.
6. Peso diário: quando o usuário escolhe oz, o valor agora é convertido para gramas antes de ser salvo, mantendo o banco em unidade-base, como já ocorre com temperatura e irrigação.
7. varieties.js e varieties.json foram sincronizados na versão de dados 1.1.0.

IMPORTANTE:
- Não alterar sw.js nesta versão.
- Não é necessário alterar o banco de dados/IndexedDB para estas mudanças.
- Faça backup antes de substituir arquivos.
- No GitHub Web, substitua os arquivos mantendo exatamente os caminhos.
